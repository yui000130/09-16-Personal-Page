歡迎來到我的個人作品集網站！這是一個結合個人介紹、專業技能、精選專案以及互動功能（即時時鐘）的響應式網頁。

---

## 📖 專案簡介 (About This Project)
這個專案旨在建立一個具備個人風格的數位名片與作品集平台。透過前端三大基礎技術（HTML5, CSS3, JavaScript），不僅完整呈現了個人背景與專業能力，還加入了即時互動的 JavaScript 時鐘功能，展現基礎前端邏輯的實作能力。

---

## ✨ 核心功能與特色 (Features)
* **👤 個人檔案 (Profile)**：展示個人大頭貼、背景故事與簡介，讓訪客快速認識我。
* **🛠️ 專業技能 (Skills)**：條列式呈現我所掌握的技術與工具（如 HTML、CSS、JavaScript 等）。
* **💼 專案展示 (Projects)**：收錄精選作品，包含專案說明與實際連結。
* **⏰ 互動即時時鐘 (Live Clock)**：使用 JavaScript 實作的動態時鐘，隨時顯示當前精確時間。
* **🎨 個人化設計 (Personal Design)**：精心調配的排版與視覺風格，打造獨一無二的介面體驗。

---

## 🛠️ 使用技術 (Tech Stack)
* **Markup**：HTML5
* **Styling**：CSS3 (Flexbox / Grid / Custom Properties)
* **Scripting**：JavaScript (ES6+)
* **Version Control**：Git & GitHub
* **Hosting**：GitHub Pages
